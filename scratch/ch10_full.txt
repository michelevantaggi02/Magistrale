it is evident then that if XT X is a singular matrix or at least ”close” to the singularity,
the uncertainty about the parameters and the estimate grows. When does this condition
occur?
In general, a square matrix U is non-invertible or singular if one of the following
equivalent conditions is true:
• det U = |U | = 0;
• At least one eigenvalue is null;
• U is Rank-deficient, i.e., one or more of its columns (or rows) is linear combination of the others.
In our case, we are interested in checking whether the design matrix X is singular.
Since we can reasonably assume that a sample cannot be a linear combination of other
samples (this is if the dataset has been properly collected), the last condition of the
previous list reduces to the following:
• X is singular if it is Column-Rank-deficient, i.e., , one or more of its columns is
linear combination of the others. In particular, it is singular if one of its features
is a linear combination of the others.
This concept is closely related to Collinearity and Multicollinearity: a feature is
multicollinear to others if its correlation with the latter is high. This means that it can
be expressed ”approximately” as a linear combination of other features. Not surprisingly, if multicollinearity is present, we observe an increase in uncertainty related to the
parameters.
In practice a feature will never be a perfect linear combination of others (unless it
was constructed as such), but strong collinearity results in ”almost” linear dependence
leading to ”almost” rank-deficiency. As a result, (XT X)−1 will become very large, greatly
increasing the variance on the parameters wM LE .
To address collinearity and multicollinearity we can use the correlation matrix and
the Variance Inflation Factor (VIF). However, the use of VIF is not optimal, because
it is not always clear what is a value of VIF that can act as a cut-off to determine
multicollinearity. Also, to compute VIF, we need to train a model for each feature,
which can become computationally prohibitive in case of datasets with many features
and many samples.
Is there another solution to handle cases where XT X → 0 and thus overfitting?

add information in order to predict t̂, so almost any value will do.
In the degenerate case where a feature is a perfect linear combination of others, we
actually get a minimization problem with inifinite solutions with respect to the parameter
associated with that feature: the variance of wM LE then becomes infinite.
This, during optimization, results in very high values for the parameters, in modulus.
Indeed, suppose that a parameter wi of a feature i becomes very large, and that this
feature is collinear to another feature j. Since the parameter wj associated to the latter
is free to assume values over a very wide range without changing the loss, to compensate
the value wi (in order to have reasonable predictions t̂ and close to the supervision label),
also wj will assume high values with opposite sign.
From this last consideration we can deduce that, in order to compensate the collinearity and avoid to have high variance values for wM LE , we can think to constrain the norm
of the parameters: this operation is called Regularization. The idea is to optimize the
value of the trainable parameters with the constraint that their norm must be small.
In this way, if a feature is collinear, the constraint will prevent the weight relative to it
from growing and indeed will cause it to cancel, since it has no impact with respect to
prediction. The regularization performs intrinsically a Feature selection: by cancelling
or reducing a lot the parameters related to collinear features or to those that are not
significant with respect to the prediction, it is implicitly reducing the degrees of freedom
of the model.
