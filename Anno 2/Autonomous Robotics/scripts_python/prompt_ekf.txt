Write a complete Python class named ExtendedKalmanFilter1D for 1D robot localization using numpy and math.

System & Models:
- State: 1D position x in [0, L]. The error variance P is a scalar float.
- Motion: x_t = x_{t-1} + u_t + w_t, w_t ~ N(0, sigma_x_loc^2).
  Prediction: x = x + u, P = P + sigma_x_loc^2.
- Measurement: Range to M landmarks: z_j = |x - m_j| + v_j, v_j ~ N(0, sigma_z_loc^2).
  Expected measurement: z_hat_j = |x - m_j|.
  Jacobian: H_j = 1.0 if (x - m_j) >= 0 else -1.0.
  Innovation: y = z - z_hat (M x 1 vector).
  Measurement noise matrix: R = np.eye(M) * sigma_z_loc^2.
  Innovation covariance: S = P * (H @ H.T) + R (P is a scalar float, use *).
  Kalman gain: K = P * (H.T @ np.linalg.inv(S)) (1 x M vector).
  State update: x = np.clip(x + (K @ y).item(), 0.0, L).
  Covariance update (Joseph form): P = (1 - (K @ H).item())**2 * P + (K @ R @ K.T).item().
  Mahalanobis distance: mu_j = y_j^2 / S_jj.

   stores parameters, sets Q = sigma_x_loc**2, R_val = sigma_z_loc**2, calls inizializza_stato().
