>[!info] Sistemi Embedded
>Sistema di supporto per l'applicazione

Un PC non è un sistema embedded, in quanto non è progettato per un singolo scopo.

>[!info] Real time
>Non indica necessariamente un'esecuzione veloce, ma comunque in tempo per l'esecuzione di una certa funzionalità (es: la temperatura di una stanza può essere controllata ogni mezz'ora)

>[!info] Decision making
>Capacità di eseguire determinati algoritmi in base ai dati forniti (nel nostro caso dai sensori), per poter interagire sull'ambiente circostante (tramite attuatori)

I sistemi embedded possono fare 3 cose:

- Elaborazione parziale e trasmissione dei dati
- Elaborazione completa
- Messa a disposizione diretta dei dati

# ASIC E FPGA

>[!important] ASIC
> Tipologie di circuiti ottimizzati su un determinato target

>[!important] FPGA
> __Field Programmable Gate Array__, contiene un hardware che si può organizzare tramite un linguaggio di programmazione hardware specifico (VHDL)

Per alcune applicazioni sono presenti direttive così stringenti da necessitare hardware custom, in questo caso si possono integrare dispositivi ASIC o FPGA.

Lo sviluppo di un ASIC è molto più costoso rispetto a quello di un FPGA, in quanto l'ASIC è un circuito creato appositamente per il problema e deve essere assemblato da macchinari estremamente costosi, infatti il suo utilizzo è sensato nel caso in cui deve essere prodotto un grande numero di componenti.

# Sistema Operativo

Nei sistemi embedded spesso non è presente il sistema operativo, ma in alcuni casi possono essere molto utili per la gestione del real time, in quanto sono stati inventati principalmente per gestire le priorità (nella robotica un esempio è il sistema operativo ROSS).

# Software E Progettazione

Lo sviluppo dei sistemi FPGA si svolgerà principalmente tramite linguaggio VHDL e i software Vitis e Vivado.
