# Supervised Learning

Si addestra il modello fornendogli dati su cui basarsi e i risultati attesi, così da poter effettuare delle previsioni.
Una volta effettuato l'addestramento passiamo alla fase di test/inference, dove il modello deve effettuare previsioni il più vicine possibili ai test.

Il supervised learning risolve 2 tipologie di problemi:
- __Regressione__: impara un modello che prevede uno o più output __continui__
- __Classificazione__: impara un modello che prevede una o più __categorie (discrete)__

# Unsupervised Learning

Non sempre abbiamo a disposizione dati per effettuare i test.
Questi modelli non vengono usati per prevedere un valore, ma per effettuare clustering raggruppando dati diversi (ad esempio le preferenze degli utenti)
